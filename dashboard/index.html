Don't trust AI code.

VerifyAgent is a CLI tool that verifies AI-generated code through execution, not guesswork. It generates adversarial tests, runs them in a sandbox, diagnoses real failures, and auto-patches the bugs.

The 6-Phase Pipeline

From code to proof in one automated loop.

1

Understand

Reads the AI-generated code and its specification. Identifies inputs, outputs, invariants, and edge cases that could break.

2

Generate Tests

Creates 12 adversarial test cases targeting common AI hallucination patterns: off-by-one, empty inputs, unicode, type mismatches.

3

Execute in Sandbox

Runs every test in an isolated Python subprocess with timeouts. Captures stdout, stderr, and exit codes as evidence.

4

Diagnose Failures

Analyzes actual tracebacks and assertion errors. Classifies root cause, severity, and which functions are affected.

5

Fix & Re-verify

Generates a targeted code patch based on the diagnosis. Re-runs all tests to confirm the fix. Retries up to 2 times if needed.

6

Report

Outputs a structured JSON report with bugs, evidence, fix diffs, and the full LLM trajectory for reproducibility.

Quickstart

Get VerifyAgent running in under 2 minutes.

1

Clone the Repository

git clone https://github.com/yourusername/verifyagent.git
cd verifyagent
2

Install Dependencies

pip install -r requirements.txt
3

Configure Your API Key

# Copy the example env file
cp .env.example .env

# Add your Gemini API key(s)
# Supports multiple keys for automatic rotation on rate limits
GEMINI_API_KEY=key1,key2,key3
4

Run VerifyAgent

# Run the full verification pipeline on all 10 evaluation cases
py run_agent.py

# Run the Agent-to-Agent REST API Server
py server.py

# Run a single case
py run_agent.py --case=case_01_array_utils

# Score the results against ground truth
py score_results.py

# Compare baseline vs agent
py generate_comparison.py

Architecture

Simple, auditable, zero-framework Python.

⚡

Gemini 3.6 Flash

Uses Google's fastest model via the google-genai SDK. Supports automatic API key rotation on rate limits.

🔒

Sandboxed Execution

All code runs in isolated Python subprocesses with strict timeouts. No network access, no file system writes.

📋

Full Trajectory Logging

Every LLM prompt and response is logged as a trajectory for complete reproducibility and auditability.

🔄

Resumable Pipeline

If interrupted by rate limits or errors, the agent automatically skips completed cases and resumes where it left off.

🔑

Multi-Key Rotation

Provide multiple API keys in .env and the client automatically rotates on 429 quota errors.

📊

Ground Truth Scoring

Built-in scoring engine computes Precision, Recall, and F1 against hidden ground truth labels for rigorous evaluation.

🤖

Agent-to-Agent REST API

Run server.py to expose a FastAPI endpoint. Other AI coding agents can send code payloads to VerifyAgent and get back verified, fixed code in JSON format.
